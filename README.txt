================================================================================
ПРОГРАММА "ООО ЕВРОБЛОК" - ПРОИЗВОДСТВО И ФИНАНСЫ
================================================================================

ТРЕБОВАНИЯ К СИСТЕМЕ:
- Windows 7/8/10/11
- Python 3.8 или выше (для запуска из исходного кода)
- Интернет-соединение (только для первичной установки reportlab)

================================================================================

ВАРИАНТ 1: ЗАПУСК ИЗ ИСХОДНОГО КОДА (для разработчиков)

1. Убедитесь, что установлен Python 3.8+
2. Откройте командную строку в папке с программой
3. Запустите: python main.py
4. При первом запуске автоматически установится reportlab

================================================================================

ВАРИАНТ 2: ЗАПУСК ИЗ EXE-ФАЙЛА (для пользователей)

СБОРКА EXE:
1. Установите PyInstaller: pip install pyinstaller
2. Запустите: python build_exe.py
3. EXE-файл будет в папке dist/Евроблок.exe

ЗАПУСК:
1. Скопируйте Евроблок.exe в нужную папку
2. Запустите двойным кликом
3. База данных создастся автоматически в той же папке

================================================================================

ВАРИАНТ 3: МНОГОПОЛЬЗОВАТЕЛЬСКАЯ РАБОТА (общая сетевая папка)

НАСТРОЙКА СЕРВЕРНОГО КОМПЬЮТЕРА:
1. Создайте папку, например C:\Euroblock
2. Скопируйте туда Евроблок.exe
3. Сделайте папку общей:
   - Правой кнопкой на папке → Свойства → Доступ
   - Расширенная настройка → Открыть общий доступ
   - Разрешения → Добавить → Все → Полный доступ

НАСТРОЙКА КЛИЕНТСКИХ КОМПЬЮТЕРОВ:
1. Откройте Проводник
2. В адресной строке: \\ИМЯ_СЕРВЕРА\Euroblock
3. Создайте ярлык для Евроблок.exe на рабочем столе

ПРИНЦИП РАБОТЫ:
- Все пользователи запускают программу из общей папки
- База данных euroblock.db создаётся в общей папке
- SQLite в WAL-режиме обеспечивает корректную параллельную работу
- Рекомендуется до 10-15 одновременных пользователей

================================================================================

ВАРИАНТ 4: МНОГОПОЛЬЗОВАТЕЛЬСКАЯ РАБОТА (клиент-сервер)

НАСТРОЙКА СЕРВЕРА:
1. На серверном компьютере скопируйте все файлы программы
2. Запустите: python server.py
3. Сервер запустится на порту 5000
4. Запомните IP-адрес сервера

НАСТРОЙКА КЛИЕНТОВ:
Способ 1 (через переменные окружения):
   set EUROBLOCK_MODE=server
   set EUROBLOCK_SERVER=http://192.168.1.100:5000
   python main.py

Способ 2 (через аргументы командной строки):
   python main.py --mode=server --server=http://192.168.1.100:5000

Способ 3 (создать ярлык):
   Цель: C:\Python\python.exe C:\Euroblock\main.py --mode=server --server=http://192.168.1.100:5000

ПРЕИМУЩЕСТВА КЛИЕНТ-СЕРВЕРНОЙ АРХИТЕКТУРЫ:
- Неограниченное число пользователей
- Нет конфликтов при записи
- Централизованное управление БД
- Не нужна общая папка

================================================================================

РЕГУЛЯРНОЕ ОБСЛУЖИВАНИЕ:

Запуск планировщика:
   python maintenance.py scheduler

Ручное обслуживание:
   python maintenance.py daily    - ежедневное обслуживание
   python maintenance.py weekly   - еженедельное обслуживание
   python maintenance.py backup   - создать резервную копию

Диагностика:
   python main.py --diagnostics

РЕШЕНИЕ ПРОБЛЕМ:

ПРОБЛЕМА: Не устанавливается reportlab
РЕШЕНИЕ:
1. Запустите командную строку от имени администратора
2. Выполните: pip install reportlab
3. Если не помогло - проверьте антивирус

ПРОБЛЕМА: Программа не запускается на другом компьютере
РЕШЕНИЕ:
1. Соберите EXE-файл: python build_exe.py
2. Скопируйте только файл dist/Евроблок.exe
3. Запустите его на другом компьютере

ПРОБЛЕМА: Медленная работа при большом количестве данных
РЕШЕНИЕ:
1. Запустите диагностику: python main.py --diagnostics
2. Выполните обслуживание: python maintenance.py daily
3. Проверьте свободное место на диске

ПРОБЛЕМА: Конфликты при многопользовательской работе
РЕШЕНИЕ:
1. Используйте клиент-серверную архитектуру
2. Запустите server.py на выделенном компьютере
3. Настройте клиентов на подключение к серверу
