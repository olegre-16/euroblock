Развёртывание на основном компьютере
1. Скопируйте ВСЮ папку dist/ на основной компьютер
   (например, в C:\Euroblock\)

2. Создайте общий доступ к папке:
   - Правой кнопкой на C:\Euroblock\ → Свойства
   - Вкладка "Доступ" → "Расширенная настройка"
   - ✓ "Открыть общий доступ к этой папке"
   - "Разрешения" → "Добавить"
   - Добавьте пользователей с правами "Изменение"
   - OK → OK → Закрыть

3. Запустите Евроблок.exe
   → Появится мастер настройки
   → Выберите "Да, это основной компьютер"
   → Запишите данные:
     * Имя компьютера: OFFICE-PC
     * IP-адрес: 192.168.1.100
     * Путь для клиентов: \\OFFICE-PC\Euroblock\euroblock.db

     Развёртывание на клиентских компьютерах
     Для каждого клиентского компьютера:

1. Скопируйте с основного компьютера:
   - Евроблок.exe
   - assets/ (папку целиком)

2. Запустите Евроблок.exe
   → Появится мастер настройки
   → Выберите "Нет, это клиентский компьютер"
   → Введите путь к БД:
     \\OFFICE-PC\Euroblock\euroblock.db
   → Нажмите "Подключиться"

3. Готово! Создан ярлык на рабочем столе.
